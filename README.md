# K-and-R-Exercises
Coding solutions to the exercises from K &amp; R: The C Programming Language, second edition.

Notes: 
  - Except where specifically noted, no attempt was made to avoid features that had not previously been covered in the book.
  - Solutions are not provided for non-coding exercises. 
  - The exercises were considered flexible prompts. I coded these in whatever way seemed most interesting. They should not be used for class submissions or for any purpose other than personal study.

All brace formatting is Allman style, which you should use too. You can thank me in 20 years.
